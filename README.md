# PC Builder

Aplicativo Android desenvolvido para auxiliar na montagem de computadores.

O usuário pode visualizar um catálogo de componentes, acessar os detalhes de cada peça, adicionar componentes à sua build e acompanhar os componentes selecionados e o valor total da configuração.

## Funcionalidades

- Catálogo de componentes de computador
- Visualização dos detalhes de cada componente
- Adição de componentes à build
- Visualização da build atual
- Remoção de componentes
- Cálculo do valor total da build
- Resumo dos componentes selecionados
- Indicação das categorias que ainda faltam na configuração

## Tecnologias utilizadas

- Kotlin
- Android Views
- XML
- ViewBinding
- RecyclerView
- Intent explícita

## Dados

Nesta etapa do projeto são utilizados dados simulados (mocks).

Não é utilizada API externa nem banco de dados.

## Telas

O aplicativo possui as seguintes telas:

1. Catálogo de componentes
2. Detalhes do componente
3. Minha Build
4. Resumo da Build
